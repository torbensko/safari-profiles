Coloured Dock launchers for individual Safari profiles, with a native editor for names and colours.

Download **SafariProfileStudio.dmg**, open it, and drag Safari Profile Studio into Applications. The app supports Apple Silicon and Intel Macs running macOS 13 or later with Safari 17 or later. Safari’s menus must be in English. Live profile launching has been verified on macOS/Safari 27.2; older supported versions still need manual testing.

Create a launcher for each profile you want, export it, then drag the exported app into the Dock. Each exported launcher needs its own Accessibility permission (Device Control and Data Access on newer macOS versions).

The downloaded Studio is Developer ID signed and notarized. Launchers generated locally are ad-hoc signed; after changing and re-exporting one, macOS may require removing and re-adding its permission entry, even if the switch is already enabled.

These icons open new windows in real Safari. Safari still owns the windows and running indicator. No background helper or separate browser is installed.
